# 圖形驗證碼升級建議書

本文件說明如何將目前的數字加法驗證碼（如 `10 + 20 = `）升級為更安全的圖形驗證碼，並使用 PHP 的 GD 函式庫進行實作。

## 1. 現況分析
- **目前機制**：在 `front/login.php` 與 `front/admin.php` 中直接生成亂數相加，並存入 `$_SESSION['ans']`。
- **驗證方式**：前端透過 AJAX 傳送使用者輸入至 `api/chk_number.php` 與 `$_SESSION['ans']` 比對。

## 2. 升級方案：PHP GD 圖形驗證碼
我們將建立一個獨立的圖片產生器，並在不改動現有驗證邏輯的情況下，僅替換顯示層。

### A. 建立圖片產生器 (`api/captcha.php`)
- **功能進階規劃**：
  1. **字元集**：包含數字 (`0-9`) 及英文大小寫字母 (`A-Z`, `a-z`)。
  2. **字元視覺**：每個字元獨立繪製，隨機產生 -15 度至 15 度的傾斜角度，且**每個字元顏色隨機變化**。
  3. **字型設定**：使用 `Arial.ttf` 字型，字級設定為 20px (至少 16px 以上)。
  4. **強化干擾線**：干擾線將固定從左側邊界延伸至右側邊界，**數量隨機產生 (4~8 條)**，以增加安全性與美感。
  5. **結果存入 Session**：維持存入 `$_SESSION['ans']` 以供驗證。

### B. 修改前端頁面 (`front/login.php`, `front/admin.php`)
- **改動點**：
  - 移除原本的 `rand()` 相加程式碼。
  - 加入 `<img src="api/captcha.php" onclick="this.src='api/captcha.php?'+Math.random()" style="cursor:pointer" title="點擊重新產生">`。
  - 使用者點擊圖片時可自動重新整理驗證碼，提升易用性。

### C. 驗證機制 (`api/chk_number.php`)
- **改動點**：**無**。
- 因為圖片產生器依然將正確答案存放在 `$_SESSION['ans']`，現有的 AJAX 驗證邏輯與伺服器端比對邏輯均可直接沿用，確保系統穩定性。

## 3. 預期效益
- **安全性**：防止簡單的網頁抓取工具（Scraper）直接讀取 HTML 中的文字來破解驗證碼。
- **易用性**：提供點擊圖片即可更新的功能，無需重新載入整個頁面。
- **開發效率**：僅需新增一個 API 並修改少量顯示程式碼，風險極低。

## 4. 系統環境要求與確認

實作圖形驗證碼需要 **PHP GD 擴充功能**。以下是確認與啟用的方式：

### A. 如何確認已啟用？
1. **建立測試檔**：建立一個 `info.php` 檔案，內容為 `<?php phpinfo(); ?>`，在瀏覽器打開後搜尋 "GD"。若看到 "GD Support => enabled" 即代表已啟用。
2. **命令列檢查**：在終端機執行 `php -m`，檢查清單中是否包含 `gd`。
3. **程式碼檢查**：可以使用 `<?php var_dump(extension_loaded('gd')); ?>` 來確認。

### B. 如何啟用 (以 Windows 為例)？
1. 找到 PHP 安裝目錄下的 `php.ini` 檔案。
2. 搜尋 `;extension=gd`。
3. **移除前端的分號**，使其變成 `extension=gd`。
4. 儲存檔案並 **重啟網頁伺服器** (如 Apache、Nginx 或 PHP 內建伺服器)。

## 5. 確認事項
- **驗證碼內容**：已確認採用 **4 位純數字** 驗證。
- **實作優先權**：在確認 GD 擴充功能已啟用的情況下，即可進行 `api/captcha.php` 的實作。
